# Navya's Portfolio

A personal portfolio website built using **React.js** and **Tailwind CSS** to showcase my skills, projects, learning journey, and interests in web development.

## About the Project

This portfolio was created to introduce myself, showcase the technologies I have learned, and present some of the projects I have worked on.

The website has a clean and responsive design and is divided into different sections for easy navigation.

## Features

* Responsive portfolio website
* Navigation bar with links to different sections
* Personal introduction and learning journey
* Skills section
* Projects showcase
* Contact form
* Footer with social profile links
* Responsive design for desktop, tablet, and mobile devices
* Animations for a more interactive user experience

## Getting Started

To run this project locally, follow these steps.

### 1. Clone the repository

```bash
git clone <your-github-repository-link>
```

### 2. Navigate to the project folder

```bash
cd <project-folder-name>
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The project will then be available on the local development server provided by Vite.

## Build for Production

To create a production build, run:

```bash
npm run build
```
